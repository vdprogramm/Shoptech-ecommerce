# ShopTech Shipper — React Native + Expo

Ứng dụng dành cho người giao hàng. Mã nguồn và Android native được giữ từ bản `ReactNative/shoptech-app` cũ (package `com.shoptech.shipper`).

Chạy từ thư mục gốc:

```bash
cd ReactNative/shipper
npm ci
npm run start:shipper
```

Thử Android: `npm run android:shipper`.

Lưu ý cập nhật Root Directory của EAS/CI sang `ReactNative/shipper`. Không đè file native bằng cấu hình Customer. Kiểm tra backend và các API giao hàng trước khi phát hành.
